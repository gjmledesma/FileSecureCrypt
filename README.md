## Sections
| Feature / Section | Image | Description |
| :------: | :---: | :---------: |
| Lock File + Remove Lock from File | <img src="public/images/FSC-Home.png" width="450" /> | <b><u>Lock File</u></b> <br> This feature enables a user to lock their site-compatible desired file with a password. Once converted, a .locked file will automatically download and be saved to the user's computer. <br><br> <b><u>Remove Lock from File</u></b> <br> This feature lets the user unlock a .locked file by entering the password the user used to lock the specific file in the first place. Once unlocked, an unencrypted file will automically download and be saved to the user's computer. |
| History of Locally Locked Files + Guide    | <img src="public/images/FSC-Home-2.png" width="421" /> | <b><u>History of Locally Locked Files</u></b> <br> This section shows the local list of what files the user has locked so far. This is automatically updated once a file has been locked successfully. <br><br> <b><u>Guide</u></b> <br> Shows how each feature works and guides what the user must do.|
