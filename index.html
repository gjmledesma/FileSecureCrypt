How Both Works

Think of locking a file like putting it inside a strong safe that only opens with a secret word. Here's what happens step by step.

🔒 Locking a File

  1. Pick a file you want to lock and protect, like a photo (JPG/PNG), a document (DOCX), a text file (TXT), or a PDF.
  2. Set a password that is at least 8 characters long. This password becomes the key to your file.
  3. Your file gets scrambled into a jumbled mess that nobody can read.
  4. You get a new locked file (a file ending in .locked). Keep it safe especially with your password as the locked file is useless to anyone without the password.

🔓 Unlocking a File

  1. Pick the locked file you created earlier.
  2. Type the same password you used to lock the file.
  3. Your file is unscrambled back to its original form.
  4. You get your original file back, ready to open or share as you please.

⚠️ If you forget your password, the file cannot be unlocked and recovered. Please keep your password in a secure place and remember it.
